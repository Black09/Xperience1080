Xperience1080
-------------

Xperience1080 is a skin for XBMC.

It started as a pure 1080p mod of the Xperience skin by Team Blackbolt.
In the meantime the skin changed fundamentally so it now hasn't much in common
with the original Xperience skin. Xperience1080 delivers you a skin with focus
on graphical quality, smooth animations and very well integrated functions/add-ons.
